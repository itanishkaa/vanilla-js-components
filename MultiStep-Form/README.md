# 📝 Multi-Step Form

A mini frontend project built using **HTML, CSS, and Vanilla JavaScript** that demonstrates how to create a multi-step registration form with step navigation, form validation, progress tracking, and final submission.

This project replicates a common user registration flow found in modern web applications, improving user experience by breaking large forms into smaller, manageable steps.

## ✨ Features

* Three-step registration form
* Interactive step indicator with progress tracking
* Previous and Next navigation
* Clickable completed steps for navigation
* Client-side form validation at each step
* Summary page displaying entered information
* Final form submission
* Responsive and clean user interface
* Smooth transitions between form steps
* Built entirely with Vanilla JavaScript (No frameworks)

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6)

## 📚 What I Learned

This project helped me understand how multi-step workflows are implemented using core JavaScript while managing application state and user interactions.

Key concepts explored include:

* Managing application state using JavaScript
* DOM selection and manipulation
* Event handling for buttons and form submission
* Creating reusable functions for navigation
* Client-side form validation using the Constraint Validation API
* Dynamically updating UI based on the current step
* Working with conditional rendering using CSS classes
* Collecting and displaying form data dynamically
* Building interactive forms without external libraries
* Creating smooth user experiences with CSS animations
