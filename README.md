# 📌 Scroll and Fix It!

A mini frontend project built using **HTML, CSS, and Vanilla JavaScript** that demonstrates how to create a sticky sidebar which remains fixed while the surrounding content continues to scroll.

This project replicates a common UI pattern used in e-commerce websites, dashboards, documentation pages, and admin panels where filters or navigation stay visible as users browse long content.

## ✨ Features

* Sticky sidebar using CSS `position: sticky`
* Sidebar remains fixed while scrolling through content
* Visual indicator when the sidebar becomes sticky
* Responsive two-column layout
* Clean and modern UI
* Built entirely with Vanilla JavaScript (No frameworks)

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6)

## 📚 What I Learned

This project helped me understand how sticky positioning works and how JavaScript can be combined with CSS to enhance user interactions.

Key concepts explored include:

* Using `position: sticky`
* Understanding the `top` property for sticky elements
* Building responsive layouts with Flexbox
* Working with the `IntersectionObserver` API
* Detecting when an element becomes sticky
* Dynamically adding and removing CSS classes
* DOM selection and manipulation
* Creating reusable UI components with Vanilla JavaScript
* Improving user experience with subtle visual feedback
