# Vanilla JS Dropdown Component

**This project is part of my Vanilla JavaScript Mini Projects series, where I'm recreating commonly used frontend components from scratch to strengthen my understanding of JavaScript, DOM manipulation, performance optimisation, and reusable UI design.**

A mini project built using **Vanilla JavaScript** to understand how reusable UI components work without relying on frameworks or external libraries.

This project recreates the core functionality of a modern dropdown component similar to **React Select**, supporting both **single-select** and **multi-select** modes along with search and accessibility features.

## ✨ Features

- Single Select Dropdown
- Multi Select Dropdown
- Search and filter options
- Close dropdown on:
  - Selecting an option (single select)
  - Clicking outside
  - Pressing the `Escape` key
  - Clicking the dropdown toggle again
- Selected option highlighting
- Reusable component architecture using JavaScript classes
- Responsive UI

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

## 📚 What I Learned

This project helped me understand how interactive UI components work under the hood without using libraries like React or React Select.

Some of the concepts I explored include:

- Building reusable components using JavaScript classes
- Managing component state
- Rendering UI dynamically
- DOM manipulation and updates
- Event handling
- Event delegation
- Search and filtering logic
- Single vs Multi Select implementation
- Detecting clicks outside a component
- Keyboard accessibility using the Escape key
- Using ARIA attributes for better accessibility
- Creating configurable and reusable components
