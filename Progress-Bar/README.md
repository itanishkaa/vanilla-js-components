# 📊 Progress Bars

A mini frontend project built using **HTML, CSS, and Vanilla JavaScript** that demonstrates different types of progress indicators commonly used in modern web applications.

The project includes three types of progress bars:

* 📜 **Scroll Progress Bar** – Displays the user's scroll progress at the top of the page.
* 📈 **Linear Progress Bar** – Updates based on a user-provided percentage value.
* 🔵 **Circular Progress Bar** – A circular representation of the same percentage using SVG.

## ✨ Features

* Scroll-based page progress indicator
* Dynamic linear progress bar
* SVG-based circular progress bar
* User input validation (0–100%)
* Smooth CSS transitions and animations
* Responsive and clean UI
* Built entirely with Vanilla JavaScript (No frameworks)

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6)
